Open saved email messages on your Mac with EML/MSG Viewer. Read the message, inspect its headers, and work with attachments in one window.

FORMATS
• Open .eml messages with MIME content, including encoded headers and character sets.
• Read Outlook .msg files without Outlook.

READING
• View HTML messages with inline images. If a message has no HTML body, the app shows its plain text body.
• See decoded From, To, Cc, Subject, and Date headers alongside the message.
• Read messages in a window that keeps the content in view.

ATTACHMENTS
• Find attachments in a bar with Finder-style file icons.
• Open an attachment in its default app, or choose Save All to save attachments to a folder you select.
• Attachment file names are sanitized when files are saved.

COMFORT
• Choose light, dark, or system appearance.
• Set the message font family and text size in settings.
• The app remembers its window size between launches.

FINDER
• Set EML/MSG Viewer as the default viewer for .eml and .msg files.
• Double-click a message in Finder to open it in the app after setting the default.

PRIVACY
• The app is sandboxed and does not require an account.
• The app collects no data and uses no analytics or tracking.
• HTML messages may load remote images from their source servers.
