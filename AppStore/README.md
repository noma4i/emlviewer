# App Store metadata

`metadata/en-US/` contains the English (U.S.) listing:

| File | Content | Apple limit |
| --- | --- | --- |
| `name.txt` | App name | 30 characters |
| `subtitle.txt` | Subtitle | 30 characters |
| `promotional_text.txt` | Promotional text | 170 characters |
| `description.txt` | Description | 4,000 characters |
| `keywords.txt` | Comma-separated search terms | 100 characters |
| `release_notes.txt` | Version 1.0 release notes | 4,000 characters |
| `support_url.txt` | Support page URL | Valid URL |
| `privacy_url.txt` | Privacy policy URL | Valid URL |
| `marketing_url.txt` | Marketing page URL | Valid URL |

`metadata/copyright.txt` identifies the rights holder. `primary_category.txt` and `secondary_category.txt` select App Store categories. `review_notes.txt` contains instructions for App Review.
